# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Every suspected vulnerability goes through this private channel.

## Scope

Reports are in scope when they affect the code in this repository:

- VeriRelay;
- the `avr/1` Receipt endpoints;
- the Bootstrap and `HOST_DATA` check;
- Provisioning client behavior;
- the SEV-SNP Attestation integration.

Findings that only concern third-party dependencies should be reported upstream as well.
